# Бета Staya: установка и обновления

Staya показывает твою позицию только друзьям, которых ты добавил сам. Координаты шифруются на телефоне; сервер видит только зашифрованные пакеты и не знает, где ты (подробно — [модель угроз](threat-model.md)). Это бета: возможны ошибки, расход батареи ещё уточняем.

Файлы каждой версии — в [релизах](https://github.com/realfamousbae/Staya/releases): `Staya-<версия>.apk` (Android), `Staya-<версия>.ipa` (iPhone) и `SHA256SUMS`.

## Android

Удобнее всего через [Obtainium](https://github.com/ImranR98/Obtainium) — он сам ставит новые версии прямо из релизов GitHub, без магазина приложений.

1. Установи Obtainium (с его страницы на GitHub или из F-Droid).
2. В Obtainium: «Добавить приложение» → адрес `https://github.com/realfamousbae/Staya` → «Добавить» → «Установить». Android попросит разрешить установку из Obtainium — разреши.
3. Все версии подписаны одним ключом, его отпечаток (SHA-256) указан в описании каждого релиза. Android сам не поставит обновление, подписанное другим ключом, поверх установленного Staya — если Obtainium или Android сообщат о несовпадении подписи, не удаляй приложение ради «обновления», а напиши автору.

Без Obtainium: скачай `.apk` из последнего релиза и открой его на телефоне. Обновления тогда — так же вручную.

### Чтобы позиция уходила в фоне

После «Делиться позицией» приложение само попросит разрешения по шагам:

- геолокация — **«Разрешить всегда»** (без неё после перезагрузки телефона передача не включится сама);
- уведомление — пока идёт передача, висит постоянное уведомление «Staya делится позицией»: так Android не останавливает её;
- **исключение из оптимизации батареи**.

Производители телефонов дополнительно останавливают фоновые приложения:

- **Xiaomi / Poco / Redmi:** настройки приложения Staya → «Автозапуск» — вкл; «Контроль активности» (или «Батарея») — «Нет ограничений».
- **Samsung:** настройки приложения Staya → «Батарея» → «Неограниченно»; «Обслуживание устройства» → «Батарея» → «Ограничения фонового использования» → добавить Staya в «Приложения, которые никогда не спят».

## iPhone

Без платного аккаунта разработчика приложение ставится через [AltStore](https://altstore.io) или [SideStore](https://sidestore.io) со своим Apple ID:

1. Установи AltStore (нужен компьютер с AltServer) или SideStore по инструкции на их сайте.
2. Скачай `.ipa` из последнего релиза на iPhone и открой его в AltStore/SideStore («Мои приложения» → «+»).
3. Бесплатный Apple ID подписывает приложение на **7 дней**: AltStore/SideStore продлевают подпись сами, если раз в неделю открывать их (AltStore — когда рядом компьютер с AltServer). Если срок истёк, Staya не откроется — просто обнови подпись, данные не пропадут.

После «Делиться позицией» разреши геолокацию **«Всегда»** и **«Точная геопозиция»**, а также «Движение и фитнес» — по нему Staya реже включает GPS, когда ты не двигаешься.

## Первый запуск

1. Получи от друга **приглашение** — QR-код при встрече или ссылку `staya://add?…`. В нём уже есть адрес сервера и отпечаток его ключа.
2. Открой Staya, вставь ссылку (или отсканируй QR после создания аккаунта), в «Дополнительно» впиши **код приглашения на регистрацию** — его даёт владелец сервера лично.
3. Ник, по желанию аватар → «Создать аккаунт».
4. Если друга добавили по ссылке, он будет «не проверен»: при встрече или голосом сверьте **код безопасности** (кнопка «Ещё» у друга) и нажмите «Совпадает». Добавленный по QR при встрече — проверен сразу.

## Как скрыть себя

- «Делиться позицией» выкл — все друзья видят «скрыл(а) позицию».
- «Заморозить позицию здесь» — друзья видят одну точку, куда бы ты ни пошёл.
- У конкретного друга («Ещё»): точно / примерно (~1 км) / ничего.
- «Удалить друга» — он сразу перестаёт видеть тебя, а ты его.

## Что сообщать автору

- Ошибки — скриншотом.
- Расход батареи за сутки (Настройки → Аккумулятор, доля Staya) — с пометкой, много ли ты перемещался.
