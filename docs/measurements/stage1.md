## Что меряем

Сколько раз и в каких условиях iOS/Android будят приложение в фоне и сколько это стоит батареи — для каждой стратегии. Приложение отправляет на сервер только метрики (`docs/server.md`), координат нет.

| Стратегия | iOS | Android |
| --- | --- | --- |
| S1 | только значимые изменения (SLC) | — (задача 1.3) |
| S2 | SLC + визиты | |
| S3 | SLC + непрерывные обновления, 100 м | |
| S4 | SLC + визиты, непрерывные только при движении | |

## Протокол для iPhone

**Перед серией** (4 стратегии × сутки почти упираются в 7 дней подписи AltStore):
1. Обновить приложение в AltStore (Refresh) прямо перед началом.
2. На экране «Staya · замер» проверить:
   - Геолокация — **всегда**, Точность — **точная**;
   - Фоновое обновление — **available**;
   - Энергосбережение — **выкл**;
   - Датчик движения (S4) — **разрешено** (если «не спрашивали», выбрать S4 при открытом экране).
3. Токен сборщика сохранён; «Тестовая отправка» → «Последний ответ: HTTP 204».

**Каждый день — одна стратегия:**
1. Выбрать стратегию, «Сбросить счётчики», включить «Запущено».
2. «Тестовая отправка» → HTTP 204 (проверка, что выбор применился).
3. Записать заряд и время начала. Дальше пользоваться телефоном как обычно: дом, дорога, город. Принудительно не закрывать приложение, кроме отдельного сценария ниже.
4. Через сутки: скриншот «Настройки → Аккумулятор» с долей Staya за 24 часа (основная метрика батареи — `battery_pct` в метриках меняется шагами ~5%) и скриншот экрана «Staya · замер».

**Отдельные сценарии** (по ходу любого дня, отметить время):
- принудительное закрытие свайпом — будит ли SLC приложение после этого;
- перезагрузка телефона;
- поездка на транспорте (для S3/S4).
